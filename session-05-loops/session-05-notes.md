# Session 05 - Loops

## Concepts Covered
- for Loop
- while Loop
- range()

## Practice Programs
- Countdown Timer
- Student Marks Entry
- Password Security System
- ATM Menu System

## Mini Project
- Student Quiz System

## Key Learnings
- The `for` loop is used when the number of repetitions is known.
- The `while` loop runs until a condition becomes false.
- `range()` controls the number of iterations in a `for` loop.
- Loops make programs shorter, cleaner, and more efficient.

## Skills Gained
- Writing for loops
- Writing while loops
- Using range()
- Repeating tasks efficiently
- Combining different types of loops in one program
