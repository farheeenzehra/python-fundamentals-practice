# Session 05 - Loops

## Goal

Understand how to repeat tasks automatically instead of writing the same code multiple times.

---

## Concepts Covered

- for Loop
- while Loop
- range()

---

## What I Learned

- `for` loop is best when I already know how many times something should repeat.
- `while` loop is used when repetition depends on a condition.
- `range()` controls how many times a `for` loop runs.
- Loops help reduce repeated code and make programs much shorter.

---

## Things I Understood

- A loop follows the same steps repeatedly until its condition is completed.
- `range(start, stop, step)` became much clearer after practicing.
- `while` loops require updating the condition; otherwise they can run forever.
- I started understanding when to choose a `for` loop and when a `while` loop is a better option.

## Reflection

This session changed the way I think about programming. Before learning loops, I had to write similar lines of code repeatedly. After practicing, I realized that one loop can replace many repeated statements. I also became more comfortable deciding whether a problem needs a `for` loop or a `while` loop.
