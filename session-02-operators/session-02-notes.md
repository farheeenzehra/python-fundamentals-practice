**Date:** 18 July 2026

## Goal

Learn how Python performs calculations, comparisons, and logical operations.

---

## Concepts Covered

- Arithmetic Operators
- Assignment Operators
- Comparison Operators
- Logical Operators
- Operator Precedence

---

## What I Learned

- Operators are used to perform different types of operations on values.
- Arithmetic operators perform mathematical calculations.
- Comparison operators compare values and always return either `True` or `False`.
- Logical operators combine multiple conditions.
- Assignment operators store or update values inside variables.
- Python follows operator precedence (BODMAS-like rules) while evaluating expressions.

---

## Things That Clicked

### "=" vs "=="

This confused me initially.

Now I understand:

- `=` → Assigns a value.
- `==` → Compares two values.

This is one of the easiest mistakes to make while learning Python.

---

### Comparison Operators

Earlier I thought comparison operators returned numbers.

Now I know they always return:

- `True`
- `False`

These values become the foundation for decision making later using `if` statements.

---

### Logical Operators

I realized they are used when one condition isn't enough.

For example:

- `and` → Both conditions must be true.
- `or` → At least one condition must be true.
- `not` → Reverses the result.

---

### Operators Have Different Jobs

Instead of memorizing operators, I started asking:

> "What do I actually want this line to do?"

Then choosing the correct operator became much easier.
