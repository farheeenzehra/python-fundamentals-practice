## What I Learned

- Every Python program follows a simple flow:

  **Input → Processing → Output**

- `print()` is used to display information to the user.
- `input()` is used to receive information from the user.
- Variables store values so they can be reused throughout the program.
- Python decides the data type automatically in many cases.
- Comments make code easier to understand without affecting execution.

---

## Things That Clicked

### print() vs input()

Initially, I mixed these two.

Now I remember them like this:

- `print()` → Talks to the user.
- `input()` → Listens to the user.

---

### Variables

At first, variables felt like random names.

Later I understood that variables are simply containers that store data so I don't have to write the same value again and again.
