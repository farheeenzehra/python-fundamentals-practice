# Session 03 - Decision Making

**Date:** 21 July 2026

---

## Goal

Learn how programs make decisions based on different conditions and user input.

---

## Concepts Covered

- if
- elif
- else
- Comparison Operators
- Logical Operators
- Nested Conditions (Introduction)

---

## What I Learned

- Programs don't always execute every line of code. They can choose different paths depending on conditions.
- Comparison operators produce either `True` or `False`.
- `if`, `elif`, and `else` allow a program to handle different situations.
- Logical operators help combine multiple conditions into one decision.
- The order of conditions matters because Python checks them from top to bottom.

---

## Things That Clicked

### Every Condition Has Only Two Results

This was the biggest realization.

A condition can only be:

- `True`
- `False`

Nothing else.

Understanding this made writing conditions much easier.

---

### Thinking Before Coding

This session taught me to stop writing code immediately.

Instead, I started asking myself:

- What are all the possible cases?
- What should happen in each case?

Then writing the `if-elif-else` structure became much easier.

---

### Comparison + Logical Operators Work Together

I realized that comparison operators and logical operators are closely connected.

Comparison operators check values.

Logical operators combine multiple comparisons into one decision.

---

## Things I Got Confused About

- When to use `if` and when to use `elif`.
- Mixing comparison operators with logical operators.
- Forgetting indentation.
- Writing conditions without first thinking about all possible cases.
