Date: 26 july 2026

## Goal

Learn how to store and manage multiple values using Python Lists.

## What I Learned

- Created lists.
- Accessed list items using indexing.
- Updated list items.
- Added items using append().
- Inserted items using insert().
- Removed items using remove().
- Used len() to count list items.
- Sorted lists using sort().
- Sorted in descending order using reverse=True.
- Used slicing to access specific parts of a list.
- Checked if an item exists using in.
- Used for loops to iterate through lists.
- Built my first mini project using lists.

## Mini Project

Student Marks Management System

## Reflection

This session helped me understand how to work with multiple values instead of just one variable. At first, I got confused with methods like sort(), append(), and indexing, but after practicing and fixing my own mistakes, I became much more comfortable using lists. Building the mini project showed me how different concepts connect together in one program.
