# Milestone Project 02 - ATM Simulator

Completed after finishing **Session 12 – File Handling**.
This project combines everything I learned from Sessions 01–12 into one application.

## About

This is my second milestone project in my Python Fundamentals learning journey.

I built this project after learning Python fundamentals, including variables, input/output, conditions, loops, functions, lists, dictionaries, exception handling, and file handling.

The goal of this project was to apply these concepts by building a simple ATM Simulator that allows users to perform basic banking operations through a menu-driven program.

---

## Features

* User Login (Username & PIN Verification)
* Check Balance
* Deposit Money
* Withdraw Money
* Transaction History
* Change PIN
* Transaction Receipt
* Multi-User Support
* Menu-Driven Program

## What I Learned

While building this project, I learned how to:

* Break a larger program into smaller functions.
* Organize code for better readability and reuse.
* Store and manage multiple users using dictionaries.
* Validate user input and handle invalid entries.
* Simulate real-world ATM operations using program logic.
* Record transaction history during program execution.
* Save and load data using file handling.
* Think more like a software engineer by designing features instead of writing isolated programs.

This project reflects my current stage of learning and is intentionally kept simple as part of my programming journey.
